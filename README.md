# Kiva & MPI — анализ займов и уровня бедности

Аналитический проект по исследованию связи между микрофинансированием Kiva и индексом многомерной бедности (MPI).

## Цель

Проверить, как уровень бедности региона связан с характеристиками займов:

- суммой;
- сроком;
- сектором;
- видом деятельности;
- характеристиками заёмщиков.

## Данные

Используются два основных источника:

1. данные о займах Kiva;
2. данные по индексу многомерной бедности MPI.

## Основные наблюдения

- регионы с более высоким MPI в среднем получают меньше займов и меньшие суммы;
- структура займов меняется в зависимости от уровня бедности;
- выраженной разницы по уровню бедности между мужчинами и женщинами-заёмщиками не обнаружено;
- по секторам и видам деятельности видны различия между регионами с разным MPI.

## Ограничения

Главное ограничение проекта — неполнота региональных данных MPI. Для более надёжных выводов требуется подключение дополнительных внешних источников.

## Что показывает проект

Проект демонстрирует объединение разнородных социально-экономических данных, исследовательский анализ и формулирование выводов с учётом ограничений исходного датасета.
